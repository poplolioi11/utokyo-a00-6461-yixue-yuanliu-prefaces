# 《醫學源流》兩序與刊記（東京大學總合圖書館 A00:6461，1611）

*Yi xue yuan liu [Two Prefaces and the Colophon of the 1611 Edition]*

東京大學總合圖書館藏《醫學源流》是熊宗立《名方類證醫書大全》的 1611 年梅壽刊本，保留吳高（尚志）序、熊宗立自序與日本刊記。兩序交代編書、分類、刊印與讀者，版面上的朱引和墨筆訓點提供漢文醫籍在日本閱讀與傳播的線索。

本版收入兩篇序文及刊記，共 7 個書面區和 51 欄。JSON 和 TEI P5 的欄位可以回到館方 IIIF 影像，TXT 另提供逐欄及連讀版。JSON 附朱引、墨筆訓點的定位示例。以兩份 AI 依圖獨立讀稿比較，回圖後保留 10 處疑讀。尚無人類全文雙校、專家審定或準確率量測。
